# T2：时间条件表达与空间预测

T2 保留两个任务：`heart`（500 基因）和 `embryo`（497 基因）。表达网络、空间网络和空间核在训练与推理间共享。成熟模型使用 3000 次基础 CFM 更新；当前心脏空间模型再执行 300 次分组梯度预算续训。推理使用 32 步积分，训练辅助损失使用 8 步积分。

## 推理

输入 NPZ 包含 `x`、`c`、`genes`。`x` 是细胞 × 基因表达矩阵；`c` 是相同细胞的原单位三维坐标；`genes` 对应 `x` 的列名。入口按基因名对齐模型面板，缺失或重复列名会报错。

```bash
python -m virtual_embryo.t2.predict --setting heart --input input.npz --output prediction.npz --source-time 8.75 --target-time 9.5 --model-dir models/t2
```

输出包含 `x`、`c`、`c_centered_unit`、`genes`，相邻 JSON 保存表达生成、校准和空间推理用时。`--baseline` 使用成熟表达及空间网络，适用于原算法对照。默认随机种子为 101，线程数为 1。省略 `--model-dir` 时使用统一资产路径。

| 设置 | 三个历史时间 | 已使用的外推时间 | 坐标单位 |
|---|---|---|---|
| heart | 8.25、8.5、8.75 | 9.5、10.5 | 358.5750427246094 |
| embryo | 6.75、7.25、7.5 | 8.0 | 122.1015853881836 |

历史时间对使用对应的 257 点分位映射。心脏外推使用末相邻历史时间对的映射并保持预测列均值；胚胎外推使用长历史时间对的映射，混合系数为 0.5。心脏空间推理使用固定种子 20261111、128 个参考点和 15 个邻居；128 行输入保留原稠密等价路径。胚胎及 baseline 保留动态近邻空间场。

## 数据准备

训练输入按时间排列为三组 NPZ，每组可含多个有序文件块。每个文件包含 `x`、`c`、`rows`、`genes`；`rows` 是原始数据行号。同一时间组的行号必须唯一，基因顺序必须与模型元数据一致。

```bash
python -m virtual_embryo.t2.prepare --setting heart --stage stage_8.25_train.npz --stage stage_8.5_train.npz --stage stage_8.75_train.npz --output training/heart_prepared.joblib --model-dir models/t2
```

有两块训练数据时，写作 `--stage first_block.npz second_block.npz`。数据准备依次计算共同坐标单位下的中心化坐标、30 维 PCA、三对软匹配计划、训练损失统计量和零值去量化阈值。旁侧 JSON 记录原始行号和文件 SHA-256。

成熟训练与最终续训使用各自冻结的行集合。准确复现旧权重时，应提供对应的历史训练数据，而不是重新抽样。仓库接受原始成熟 `prepared.joblib` 的字典式阶段格式，也接受本工具生成的元组式阶段格式。

## 训练及校准

从零训练成熟 control（心脏和胚胎各执行一次）：

```bash
python -m virtual_embryo.t2.train --setting heart --mode control --prepared training/heart_mature_prepared.joblib --output models/t2/heart_control.pt --model-dir models/t2 --steps 3000 --seed 1
```

成熟 control 使用 Adam，学习率 0.0005、批量 128、梯度范数上限 10。每次更新循环使用 `(0,1)`、`(1,2)`、`(0,2)` 三个历史时间对。

最终心脏空间续训：

```bash
python -m virtual_embryo.t2.train --setting heart --mode continue --prepared training/heart_prepared.joblib --output models/t2/heart_spatial_continued.pt --model-dir models/t2 --steps 300 --seed 1
```

续训从 `heart_control.pt` 加载两个网络，重新建立 Adam，学习率 0.0001。表达和空间参数分别计算基础损失与辅助损失的梯度预算，辅助梯度比例为 0.25，并保留初始梯度的 0.1 倍下限及系数上限 1。两个网络都参与更新；最终推理读取续训的空间权重，表达仍使用成熟 control。训练输出保留两个网络的权重及训练日志，资产导出时只保留实际部署字段。

用历史训练行拟合分位映射（心脏和胚胎各执行一次）：

```bash
python -m virtual_embryo.t2.calibrate --setting heart --prepared training/heart_prepared.joblib --output models/t2/heart_maps.joblib --model-dir models/t2
```

校准对三个历史时间对分别使用种子 201、202 生成表达，拼接后拟合 257 个分位点。分位映射使用成熟表达权重。以上入口支持 `--threads`；训练入口另支持 `--device`，默认为 CPU。

## 清理与验证

清理移除了旧实验模块导入、候选搜索分支、源代码字符串替换训练器，以及重复的网络和空间核。模型资产去除了 optimizer、随机数状态和未使用的续训表达权重；baseline 保留完整成熟表达与空间权重。空间邻域的无自环处理、零支撑半径分支、心脏外推的均值及容量约束继续参与计算。

2026-11-14 验证使用同一 CPU 环境：10 组历史/外推/baseline/128 行推理结果逐值相同；两任务全部 3 对分位映射重拟合后逐值相同；心脏数据准备的阶段、计划、统计量、阈值及基因顺序逐值相同；成熟 control 与心脏续训各执行 2 次更新，新旧全部参数逐值相同。可移植测试另覆盖基因重排、缺失面板、baseline 独立运行、重复坐标、自环排除和训练到推理的完整流程。
