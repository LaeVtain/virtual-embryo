# T2 运行与参数

安装、资产导入、统一评估和 H5AD 导出见 [README](../README.md)。默认模型目录为 `models/t2`，可用 `--model-dir` 指定。

## 输入与模型文件

- 推理 NPZ：`x` 为表达矩阵，`c` 为原单位三维坐标，`genes` 为基因名；heart 500 基因，embryo 497 基因。
- 训练 NPZ：另含原始行号 `rows`，同阶段行号唯一；列顺序与 `metadata.json` 一致。三个阶段细胞数相等且各不少于 128。
- 模型目录：`config.json`、`metadata.json`、`{heart,embryo}_control.pt`、`{heart,embryo}_maps.joblib`、`heart_spatial_continued.pt`。

## 数据准备、训练与校准

`--stage` 按时间顺序提供三次：heart 为 8.25、8.5、8.75；embryo 为 6.75、7.25、7.5。同阶段多个文件写为 `--stage block1.npz block2.npz`。

```bash
python -m virtual_embryo.t2.prepare --setting heart --stage data/heart_8.25.npz --stage data/heart_8.5.npz --stage data/heart_8.75.npz --output data/heart_prepared.joblib

# 从零训练 control
python -m virtual_embryo.t2.train --setting heart --mode control --prepared data/heart_prepared.joblib --output models/t2/heart_control.pt

# 心脏空间模型续训
python -m virtual_embryo.t2.train --setting heart --mode continue --prepared data/heart_prepared.joblib --output models/t2/heart_spatial_continued.pt

# 拟合表达分位映射
python -m virtual_embryo.t2.calibrate --setting heart --prepared data/heart_prepared.joblib --output models/t2/heart_maps.joblib
```

embryo 使用同样的 `prepare`、`control` 和 `calibrate` 命令，替换任务名、阶段输入及输出文件名。`continue` 仅支持 heart，读取模型目录中的 `heart_control.pt`。训练输出 checkpoint 及同名 JSON/JSONL 日志，校准输出映射文件。

## 推理

```bash
python -m virtual_embryo.t2.predict --setting heart --input data/heart_input.npz --output outputs/heart.npz --source-time 8.75 --target-time 9.5
```

输出 NPZ 含 `x`、`c`、`c_centered_unit`、`genes`，同名 JSON 记录运行时间。使用新训练的权重时，按上述文件名放入模型目录，再通过 `--model-dir` 选择。

## 参数

| 参数 | 适用入口 | 说明 / 默认值 |
|---|---|---|
| `--setting` | 全部 | 必填，`heart` 或 `embryo` |
| `--model-dir` | 全部 | 默认 `models/t2`，或 `VIRTUAL_EMBRYO_ASSETS/t2` |
| `--threads` | 全部 | CPU 线程数，默认 1 |
| `--mode` | train | 必填，`control` 从零训练；`continue` 心脏续训 |
| `--steps` | train | control 默认 3000；continue 默认 300 |
| `--seed` | train / predict | 训练默认 1；推理默认 101 |
| `--device` | train | 默认 `cpu`，可指定 `cuda:0` |
| `--source-time`、`--target-time` | predict | 必填，输入与目标时刻 |
| `--baseline` | predict | 使用 control 表达与空间权重，跳过分位映射 |
