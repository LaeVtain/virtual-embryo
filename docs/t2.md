# T2 运行与参数

## 外部整胚表达图谱校正

该研究入口用外部整胚单细胞图谱估计各基因的时间曲线。仓库文件 `models/t2/embryo_stage_atlas.npz` 包含五个允许日龄共同测量的 445 个基因。使用目标日龄两侧的官方输入供模型插值，其余共享日龄用于估计测量方法间的表达变化幅度。

```bash
python -m virtual_embryo.t2.atlas_interpolate --stage 6.75 data/E6.75.h5ad --stage 7.25 data/E7.25.h5ad --stage 7.5 data/E7.5.h5ad --stage 8.0 data/E8.0.h5ad --target-time 7.75 --atlas models/t2/embryo_stage_atlas.npz --panel data/T2__embryo__test_interp.genes.txt --cells 4096 --seed 101 --output outputs/embryo_atlas.npz
python -m virtual_embryo.export --input outputs/embryo_atlas.npz --output outputs/embryo_atlas.h5ad
```

## 本轮整胚预测

输入为含实测 `obs["celltype"]` 的官方空间 H5AD，或含 `x`、`c`、`genes` 和 `celltype` 的 NPZ。默认的 `--spatial-model sections` 使用全阶段分子时钟、三维配准和组织比例曲线，并分别跟踪切片平面内的两个宽度和切片深度。两端组织名称发生变化时，模型依据各组织相对于自身标本的表达特征重新分组。`compartments` 复现按主轴长度次序估计尺度的版本，`registered` 复现调整组织比例前的版本，`landmarks` 仅使用分子时钟与细胞类型地标。

```bash
python -m virtual_embryo.t2.embryo_interpolate --stage 6.75 data/E6.75.h5ad --stage 7.25 data/E7.25.h5ad --stage 7.5 data/E7.5.h5ad --stage 8.0 data/E8.0.h5ad --target-time 7.75 --panel data/T2__embryo__test_interp.genes.txt --cells 4096 --seed 101 --spatial-model sections --match-capture-depth --section-volume --sample-sections --output outputs/T2__embryo__test_interp.npz
python -m virtual_embryo.export --input outputs/T2__embryo__test_interp.npz --output outputs/T2__embryo__test_interp.h5ad
```

安装、资产导入、统一评估和 H5AD 导出见 [README](../README.md)。

## 两阶段整胚基准与本轮心脏预测

胚胎插值使用 E7.5 和 E8.0，心脏外推使用 E9.5 和 E10.5。E7.5 与 E10.5 取自队伍在 P3 选择开放的验证数据。输入使用官方 H5AD 的 `X` 和 `obsm["spatial_3D"]`，也可提供包含 `x`、`c`、`genes` 的 NPZ。`--panel` 指向相应榜单的官方面板，每行一个基因。此入口直接从两个实测群体估计目标，无需权重文件。

```bash
python -m virtual_embryo.t2.temporal --earlier data/E7.5.h5ad --earlier-time 7.5 --later data/E8.0.h5ad --later-time 8.0 --target-time 7.75 --cells 4096 --panel data/T2__embryo__test_interp.genes.txt --output outputs/T2__embryo__test_interp.npz
python -m virtual_embryo.export --input outputs/T2__embryo__test_interp.npz --output outputs/T2__embryo__test_interp.h5ad

python -m virtual_embryo.t2.heart_forecast --earlier data/E9.5.h5ad --earlier-time 9.5 --later data/E10.5.h5ad --later-time 10.5 --target-time 12.5 --cells 8192 --panel data/T2__heart__test_extrap.genes.txt --trend models/t2/heart_ventricular_trend.csv --anatomy models/t2/heart_e145.npz --spatial-rna models/t2/heart_spatial_niches.npz --state-reference models/t2/heart_state_095_145.npz --state-strength animal-horizon --output outputs/T2__heart__test_extrap.npz
python -m virtual_embryo.export --input outputs/T2__heart__test_extrap.npz --output outputs/T2__heart__test_extrap.h5ad
```

`--seed` 默认 101。`--cells` 指定输出的细胞数，插值时上限为两个输入群体中较小的细胞数，外推时上限为较晚群体的细胞数。以下为原有单阶段神经网络的训练、校准和推理入口，默认模型目录为 `models/t2`。

心脏入口的 `--trend` 参数读取以基因名为索引的两列数据。仓库内的 `heart_ventricular_trend.csv` 取自 GSE51483 中 E9.5、E14.5、E18.5 的 18 张原始心室芯片。相邻区间分别进行标准化，再估计每日表达变化。使用上一轮心脏方法时，可调用 `virtual_embryo.t2.temporal` 的相同时间与输入参数，并省略 `--trend`。

`--anatomy` 指向 LAMA E14.5 微米尺度的心脏体素坐标和半径文件。加入它时，输入坐标须使用微米，目标时刻须位于最近观测与 E14.5 之间。省略该参数可复放心室表达及近两阶段尺度模型。

`--spatial-rna` 指向 MOSTA 空间 RNA 的心脏邻域参考。它使用 E9.5、E14.5 各两只小鼠的切片原始计数，适用于 E9.5 及以后的源阶段。缺省时复现仅用心室表达与解剖参考的模型。

心脏命令使用按独立动物数据确定的时长门限，对应参数为 `--state-reference models/t2/heart_state_095_145.npz --state-strength animal-horizon`。近期 H5AD 需要包含 `obs["celltype"]` 与 `layers["counts"]`。模型在预测跨度达到 2 日时使用 E9.5 与 E14.5 心脏参考修正各组织基因检出率。

心脏外推命令可添加 `--stratified-molecules`。它依据源细胞的抽样概率校正基因分子比例，按基因预期检出细胞数分层抽样。该参数适用于对照不同分子抽样方案，使用相同的源细胞及空间坐标。

整胚插值命令可添加 `--match-capture-depth`。分子时钟按各可见阶段共有的组织标签和面板分子总数区间估计。输入使用带 `layers/counts` 的 H5AD，或含 `counts` 基因计数矩阵的阶段 NPZ。与 `--spatial-model sections` 同用时，组织比例和物理切片轴仍按原流程计算。

`--section-volume` 使用源标本逐张切片的组织面积和实际层间距校准目标标本的整体半径。各标本须有至少三层重复 z 坐标的物理切片，三个坐标轴须使用同一长度单位。`--sample-sections` 用配准后的来源细胞估计切片方向，按实测层间距和深度分布恢复目标切片。

## 输入与模型文件

- 推理 NPZ：`x` 为表达矩阵，`c` 为原单位三维坐标，`genes` 为基因名；heart 500 基因，embryo 497 基因。
- 训练 NPZ：另含原始行号 `rows`，同阶段行号唯一；列顺序与 `metadata.json` 一致。三个阶段细胞数相等且各不少于 128。
- 模型目录：`config.json`、`metadata.json`、`{heart,embryo}_control.pt`、`{heart,embryo}_maps.joblib`、`heart_spatial_continued.pt`。

## 数据准备、训练与校准

`--stage` 按时间顺序提供三次：heart 为 8.25、8.5、8.75；embryo 为 6.75、7.25、7.5。同阶段多个文件写为 `--stage block1.npz block2.npz`。

```bash
python -m virtual_embryo.t2.prepare --setting heart --stage data/heart_8.25.npz --stage data/heart_8.5.npz --stage data/heart_8.75.npz --output data/heart_prepared.joblib

# 从零训练 control
python -m virtual_embryo.t2.train --setting heart --mode control --prepared data/heart_prepared.joblib --output models/t2/heart_control.pt

# 心脏空间模型续训
python -m virtual_embryo.t2.train --setting heart --mode continue --prepared data/heart_prepared.joblib --output models/t2/heart_spatial_continued.pt

# 拟合表达分位映射
python -m virtual_embryo.t2.calibrate --setting heart --prepared data/heart_prepared.joblib --output models/t2/heart_maps.joblib
```

embryo 使用同样的 `prepare`、`control` 和 `calibrate` 命令，替换任务名、阶段输入及输出文件名。`continue` 仅支持 heart，读取模型目录中的 `heart_control.pt`。训练输出 checkpoint 及同名 JSON/JSONL 日志，校准输出映射文件。

## 推理

```bash
python -m virtual_embryo.t2.predict --setting heart --input data/heart_input.npz --output outputs/heart.npz --source-time 8.75 --target-time 9.5
```

输出 NPZ 含 `x`、`c`、`c_centered_unit`、`genes`，同名 JSON 记录运行时间。使用新训练的权重时，按上述文件名放入模型目录，再通过 `--model-dir` 选择。

## 参数

| 参数 | 适用入口 | 说明 / 默认值 |
|---|---|---|
| `--setting` | 全部 | 必填，`heart` 或 `embryo` |
| `--model-dir` | 全部 | 默认 `models/t2`，或 `VIRTUAL_EMBRYO_ASSETS/t2` |
| `--threads` | 全部 | CPU 线程数，默认 1 |
| `--mode` | train | 必填，`control` 从零训练；`continue` 心脏续训 |
| `--steps` | train | control 默认 3000；continue 默认 300 |
| `--seed` | train / predict | 训练默认 1；推理默认 101 |
| `--device` | train | 默认 `cpu`，可指定 `cuda:0` |
| `--source-time`、`--target-time` | predict | 必填，输入与目标时刻 |
| `--baseline` | predict | 使用 control 表达与空间权重，跳过分位映射 |
