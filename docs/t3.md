# T3 运行与参数

安装、资产导入、统一评估和 H5AD 导出见 [README](../README.md)。默认模型目录为 `models/t3`。已知基因使用 `tilt.npz`、`mab.npz`、`gata.npz`。2026-11-24 的 β-catenin 预测使用 `bcatenin-v4`、`bcatenin-v2.npz` 和 `developmental_response.npz`。[版本参数与参考库重建](../releases/2026-11-24/README.md)

## 输入与输出

- 推理 NPZ：`x` 为 N×500 的 `log1p(total=10000)` 表达矩阵，`c` 为 N×3 坐标，`genes` 为基因名。一次传入完整 WT 群体。
- 训练 NPZ：WT 和 KO 各包含 `x`、`genes`；使用文件中的全部行，需预先划分训练数据。Gata4 校准使用 KO1。
- 推理输出：`x`、`c`、`genes`、`source_indices`、`weights`；输出文件须使用新路径。
- 训练输出：`tilt.npz`、已训练的条件参数、`training.json`；初始化目录中的其他条件一并保留。

## 训练与校准

冻结已有状态参数，仅更新 KO 分位映射：

```bash
python -m virtual_embryo.t3.train --wt data/mab_wt_train.npz --ko data/mab_ko_train.npz --condition Mab21l2 --output-dir outputs/t3_mab
python -m virtual_embryo.t3.train --wt data/gata_wt_train.npz --ko data/gata_ko1_train.npz --condition Gata4 --initial-model-dir outputs/t3_mab --output-dir outputs/t3
```

重新训练状态参数与分位映射：

```bash
python -m virtual_embryo.t3.train --wt data/mab_wt_train.npz --ko data/mab_ko_train.npz --condition Mab21l2 --fit-state --output-dir outputs/t3_mab_new
python -m virtual_embryo.t3.train --wt data/gata_wt_train.npz --ko data/gata_ko1_train.npz --condition Gata4 --fit-state --initial-model-dir outputs/t3_mab_new --output-dir outputs/t3_new
```

## 推理

```bash
python -m virtual_embryo.t3.predict --input data/gata_wt.npz --output outputs/gata_prediction.npz --condition Gata4 --model-dir models/t3
```

使用上面新训练的模型时，将 `--model-dir` 改为 `outputs/t3_new`。

### β-catenin 跨基因预测

使用官方 E8.75 WT 的空间表达和三维坐标。统一运行入口使用种子 101 从野生型细胞中不放回抽取 7,449 个并按原行号排序。单项示例中的 NPZ 须包含该批细胞，每行表达单位为 `log1p(total=10000)`。预测返回相同的细胞数和坐标，输出基因按模型面板排列。提交文件须对齐官方面板顺序。

```bash
python -m virtual_embryo.t3.predict --input data/e875_wt_sample.npz --output outputs/bcatenin_prediction.npz --condition bcatenin-v4 --model-dir data/assets-2026-11-24/models/t3
python -m virtual_embryo.export --input outputs/bcatenin_prediction.npz --output outputs/bcatenin.h5ad
```

第四版叠加发育阶段的逐基因分位数、检出深度和谱系响应，用同龄野生型细胞的三维位置输出预测。第三版在第二版的逐基因预测分布上，结合野生型与预测突变体的细胞表达排序，两者各占一半。使用 `--condition bcatenin-v3` 或 `bcatenin-v2` 可分别回放这两个历史版本。

第二版使用 E9.5 Mab21l2 WT/KO、E8.5/E9.5 野生型 RNA，以及 E8.25、E8.5、E10.5 三个发布阶段的心脏 WT 空间 NPZ。每份额外空间参考至少含 6,400 个细胞，按下面的时间顺序传入。

```bash
python -m virtual_embryo.t3.atlas_response --wt data/mab_wt.npz --ko data/mab_ko.npz --atlas data/heart_8.25.npz data/heart_8.5.npz data/heart_10.5.npz --rna data/E8.5_RNA.h5ad data/E9.5_RNA.h5ad --output outputs/t3_transfer/bcatenin-v2.npz
```

第一版使用 E9.5 的 Mab21l2 WT/KO 空间数据和 E8.5、E9.5 的野生型 RNA 生成参数。推理时显式指定 `--condition bcatenin-v1` 可回放第一版。

```bash
python -m virtual_embryo.t3.train_transfer --wt data/mab_wt.npz --ko data/mab_ko.npz --rna data/E8.5_RNA.h5ad data/E9.5_RNA.h5ad --output outputs/t3_transfer/bcatenin.npz
```

在本研究工作区根目录运行 `python Optimization_round2/t3/build.py --output-dir outputs/t3_p3_v2` 可生成第二版模型、指定细胞群的 NPZ、按官方面板排序的 H5AD 及校验清单。第一版的对应命令为 `python Optimization_20261119/t3/build.py --output-dir outputs/t3_p3_v1`。

## 参数

| 参数 | 适用入口 | 说明 / 默认值 |
|---|---|---|
| `--condition` | train / predict | 两个入口均支持 `Mab21l2`（`mab`）和 `Gata4`（`gata`）。predict 另支持 `bcatenin`（`Ctnnb1`）、`bcatenin-v1`、`bcatenin-v2`、`bcatenin-v3` 和 `bcatenin-v4` |
| `--model-dir` | predict | 默认 `models/t3`，或 `VIRTUAL_EMBRYO_ASSETS/t3` |
| `--seed` | predict | 默认 101 |
| `--initial-model-dir` | train | 初始化参数目录；冻结校准默认读取模型资产，`--fit-state` 默认从零拟合 |
| `--fit-state` | train | 拟合 PCA8、状态系数和分位映射；省略时只校准分位映射 |
| `--projection` | train | `--fit-state` 下复用指定 `tilt.npz` 投影，基因顺序须匹配 |
| `--support-size` | train | 状态训练支持细胞数，默认 256 |
| `--support-seed` | train | 支持集采样种子，默认 1 |
| `--support-indices` | train | NPY 格式的 WT 行下标，优先于支持集数量和种子 |
| `--steps` | train | 状态拟合更新次数，默认 800 |
