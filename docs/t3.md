# T3：状态重采样与 KO 分位映射

当前模型支持 Mab21l2 E9.5 与 Gata4 E8.75。模型先对 WT 的非扰动基因作 8 维状态投影，以 softmax 权重重采样完整 WT 细胞，再把各基因的批次经验秩映射到 KO 训练集的检出率和 65 点正表达分位。表达与坐标使用同一来源行索引，输出每行在线性空间归一到 10000。

## 输入和推理

NPZ 输入包含 `x`（N×500，`log1p(total=10000)`）、`c`（N×3）和 `genes`（500 个基因名）。入口按模型基因顺序重排列。一次传入完整待预测 WT 群体：经验秩依赖这次输入的所有细胞，拆批会改变结果。

```bash
python -m virtual_embryo.t3.predict --input gata_wt.npz --output gata_prediction.npz --condition Gata4 --seed 101 --model-dir models/t3
```

`--model-dir` 默认使用 `VIRTUAL_EMBRYO_ASSETS/t3`；未设置环境变量时使用仓库的 `models/t3`。条件也可写为 `mab`、`gata`。输出包含 `x`、`c`、`genes`、`source_indices` 和 `weights`，`weights` 对应输入 WT 行，`source_indices` 对应输出采样行。输出文件使用新路径。

```python
from virtual_embryo.t3.predict import predict

result = predict(x, coordinates, genes, "Mab21l2", seed=101, model_dir="models/t3")
```

## 重建当前最终校准

最终配方使用各条件原来的 1024 行 WT 与 1024 行 KO 训练数据，冻结 mean8 support1 状态系数，重新估计 KO 检出率和正表达分位。训练 NPZ 只需 `x` 和 `genes`，预处理与推理相同，KO 列可按任意基因顺序提供。

```bash
python -m virtual_embryo.t3.train --wt mab_wt_train.npz --ko mab_ko_train.npz --condition Mab21l2 --initial-model-dir models/t3 --output-dir fitted/t3-mab
python -m virtual_embryo.t3.train --wt gata_wt_train.npz --ko gata_ko1_train.npz --condition Gata4 --initial-model-dir fitted/t3-mab --output-dir fitted/t3
```

初始化目录包含 `tilt.npz` 与条件模型。训练输出会保留初始化目录中的另一条件，最终得到三份参数文件及 `training.json`。省略 `--initial-model-dir` 时，冻结校准从默认模型资产读取初始化。Gata4 最终训练使用 KO1；KO2用于独立评价。

请先按实验划分构造训练 NPZ；入口使用文件中的全部行，不自动抽取训练/验证集。复现既有参数应使用原训练行及其顺序。当前训练代码保留历史校准的一线程 BLAS 运算顺序。

## 训练 state8 初始化

`--fit-state` 依次拟合 PCA8、mean8 状态系数和 KO 分位。PCA 使用全部 WT 训练行，去掉扰动基因，逐基因标准差下限 0.1，`svd_solver="full"`，投影维度标准差下限 `1e-8`。

mean8 损失是支持细胞加权表达均值相对 KO 均值的标准化平方误差，除以均匀支持权重的基准误差，再加 `0.1/2 * ||beta||²`。沿用 Adam 学习率 0.03、800 次更新、梯度范数上限 10、系数范围 [-4, 4]。默认支持集为 256 个 WT 训练行、support seed 1；各条件使用原配方 `20261104 + 100 * support_seed + condition_index`，Mab 的索引为 0，Gata 为 1。

```bash
python -m virtual_embryo.t3.train --wt mab_wt_train.npz --ko mab_ko_train.npz --condition Mab21l2 --fit-state --output-dir trained/mab
python -m virtual_embryo.t3.train --wt gata_wt_train.npz --ko gata_ko1_train.npz --condition Gata4 --fit-state --initial-model-dir trained/mab --output-dir trained/t3
```

可用 `--support-indices support.npy` 显式指定相对于 WT 训练文件的支持行下标；它优先于 `--support-size` 和 `--support-seed`。`--projection models/t3/tilt.npz` 在 `--fit-state` 模式下复用已有投影，仅拟合状态系数和目标分位。该投影的基因顺序须与训练面板一致。`--steps` 可缩短本地冒烟训练，默认完整训练为 800 步。

## 评价和提交格式

```bash
python -m virtual_embryo.evaluate --task T3 --prediction gata_prediction.npz --truth gata_ko_heldout.npz --reference gata_wt.npz --output t3_metrics.json
python -m virtual_embryo.export --input gata_prediction.npz --output gata_prediction.h5ad
```

评价输出 DE 分数、DE 方向、RBF MMD、variogram、severity slope 及诊断值。训练集、留出 KO 和来源 WT 的划分由输入文件确定。大群体评价可通过 `--max-cells` 和 `--seed` 固定抽样规模与种子。

## 资产与清理验证

模型仅含 `tilt.npz`、`mab.npz`、`gata.npz`，共 343,118 字节。投影和冻结状态系数也是训练初始化资产。`virtual_embryo.t3.assets.export_assets(workspace, destination)` 从已有工作区导出这三份文件，并返回大小与 SHA256。

已完成 Mab 53,742 行、Gata 24,826 行各三个推理种子的逐值回放，表达、坐标、来源索引、权重、基因名均与当前优化版本一致；另验证了两组 2048 行基因重排。两条件的 1024 行校准精确重建现有参数，PCA8 投影数组重建一致，mean8 的 12 次更新与原函数逐值一致。仓库测试覆盖校准、投影、优化收敛及训练/推理 CLI。
