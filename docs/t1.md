# T1：表达时序预测

当前配方由原 control 模型、fullELBO30 模型和三个 dv50long 教师组成。表达覆盖 32,285 个基因，输入与 `models/t1/genes.json` 顺序一致，单位为 `log1p(10000 × composition)`。

## 资产

```powershell
python -m virtual_embryo.t1.assets --workspace /path/to/original/workspace --destination models/t1
```

Python 调用为 `export_assets(workspace: Path, destination: Path) -> dict`。导出的目录为：

```text
models/t1/
  manifest.json
  genes.json
  control_initialization.json
  inference/{original,fullELBO30,teacher11,teacher22,teacher33}.pt
  training/{original,fullELBO30}.pt
  prepared/probe.joblib
  prepared/coupling_{0_1,1_2,0_2}.json
  prepared/pairs_{0_1,1_2,0_2}.npz
```

推理权重移除了 `target_encoder` 和 `posterior`；训练权重保留这两个模块。导出过程同时移除原权重中的优化器、旧随机数状态及推理用不到的训练记录；原 control 的初始化统计单独保存。五个推理模型的张量共 670,226,380 字节，原五个 checkpoint 文件共约 1.178 GB。训练初始化权重和固定训练预处理资产另行保留。

## 推理

```powershell
python -m virtual_embryo.t1.predict --model-dir models/t1 --input input.npz --output-dir outputs/t1 --source-time 9.5 --target-time 10.5 --seed 101
```

输入支持含 `x` 数组的 NPZ、SciPy CSR NPZ、NPY 和 H5AD。输出是 `candidate.npy`、`genes.json`、`audit.json`，以及 9.5→10.5 路由计算使用的磁盘中间数组。中间数组属于运行产物。

| 时段 | 推理过程 |
|---|---|
| 9.5→10.5 | 原 control 固定逐基因非零数量；fullELBO30 决定结构；三个独立教师提供均值；300 步全局均值/方差投影 |
| 其他输入时段 | fullELBO30 prior sampling |

推理保留四条 NumPy 独立随机流、32 行采样块、教师种子偏移 `0/10000/20000`、稳定排序和原投影更新顺序。

## 最终模型训练

本机当前优化使用从原 control 开始的继续训练。输入目录需要三个 SciPy CSR 文件：`train_8.5.npz`、`train_9.5.npz`、`train_10.5.npz`，每个阶段使用原固定的 1,024 个训练细胞。固定 probe、温度和配对表由资产导出器保存。

```powershell
python -m virtual_embryo.t1.train all --data-dir data/t1 --model-dir models/t1 --output-dir outputs/t1_train
```

`all` 先以 seed 22 从 `training/original.pt` 执行 fullELBO30，再从新训练的结果分别训练 seed 11、22、33 的教师。

| 配方 | 初始化 | 更新 |
|---|---|---|
| `full-elbo` | 原 control | Adam `1e-5`，30 epoch，batch 128，720 次更新；全参数 ELBO |
| `teacher` | fullELBO30 | Adam `1e-5`，batch 64，三次重复固定 48 步曝光，共 144 次更新 |

教师只在 9.5→10.5 对加入 detection/variance 项。两项初始梯度预算各占基础梯度范数的 25%，合并辅助梯度受 50% 预算约束；其余两对执行 ELBO。所有更新使用原梯度裁剪阈值 10。

单独训练、指定初始化或进行短运行：

```powershell
python -m virtual_embryo.t1.train full-elbo --data-dir data/t1 --model-dir models/t1 --output-dir outputs/full
python -m virtual_embryo.t1.train teacher --data-dir data/t1 --model-dir models/t1 --seed 11 --output-dir outputs/teacher11
python -m virtual_embryo.t1.train full-elbo --data-dir data/t1 --prepared-dir models/t1/prepared --checkpoint models/t1/training/original.pt --max-steps 1 --output-dir outputs/smoke
```

每个训练结果包含 `model.pt`（完整网络、优化器、随机流或梯度预算状态）、`inference.pt`（精简推理网络）和 `training.json`。新结果写到独立输出目录。`--checkpoint` 表示当前配方的初始化网络；每次配方建立自己的 Adam 优化器。

将 `all` 的完整训练结果装配成新的可选择推理目录：

```powershell
python -m virtual_embryo.t1.assets --trained-run outputs/t1_train --base-model-dir models/t1 --destination models/t1_retrained
python -m virtual_embryo.t1.predict --model-dir models/t1_retrained --input input.npz --output-dir outputs/t1_retrained --source-time 9.5 --target-time 10.5
```

装配步骤复用原 control、基因顺序和网络配置，接入新 fullELBO30 和三个教师，并重新记录权重 SHA-256。

## 原 control 从零训练

`control` 保留原 control 的 seed 1、Adam `0.001`、batch 128、12 epoch 和逐转换完整噪声生成顺序。它需要原始全量训练矩阵，以及包含 12 个 epoch 的 `pairs_*.npz` 配对表。下载到本机的原模型包提供了 checkpoint、代码和初始化统计，原服务器的全量矩阵和 12 epoch 配对表需要单独提供。

```powershell
python -m virtual_embryo.t1.train control --data-dir original_full_train --prepared-dir original_control_prepared --initialization models/t1/control_initialization.json --device cpu --output-dir outputs/control
```

固定 1,024 行的继续训练配对表用于上述 fullELBO30/教师流程；原 control 使用对应全量训练集的配对表。`--device cuda:0` 可用于原 control 的 GPU 训练。

## 评估

项目统一评估入口提供比赛主指标。T1 还保留基于固定训练 probe 的历史留出集诊断：

```powershell
python -m virtual_embryo.t1.evaluate --prediction outputs/t1/candidate.npy --target data/t1/dev_10.5.npz --model-dir models/t1 --output outputs/t1/heldout_metrics.json
```

该入口输出 detection MAE/MSE、均值 MAE、方差 MAE、投影协方差误差、cluster TV、RBF MMD 和组成总量检查，结果标记为 `historical_cell_holdout`。

## 清理与核验

保留的运行代码去除了跨历史实验目录的动态导入、fullELBO30 不可达的 prior-only 分支、旧轮次前缀检查，以及教师损失未使用的 PCA、MMD、方向和 variogram 计算。训练与推理共享网络定义，训练参数注册顺序保持一致。

```powershell
python -m pytest tests/test_t1.py -q
$env:VIRTUAL_EMBRYO_LEGACY_WORKSPACE='/path/to/original/workspace'
python -m pytest tests/test_t1_legacy.py -q
```

历史回放检查使用真实 32,285 基因权重和训练细胞：五个网络分别在三个时段的采样输出逐元素相等；三个完整推理路由的最终输出逐元素相等；ELBO 全部分项、一次 Adam 更新、连续两次教师梯度预算更新后的全部参数逐元素相等。另检查从零初始化和首步更新与原 control 实现一致。
