安装、模型导入和统一评估见 [README](../README.md)。

## P3 测试预测

默认使用 `lineage_forecast`，同时读取整细胞与单核心脏参考。输入包括官方 E10.5 源 RNA、用于校准测序差异的官方 E8.5 RNA、官方面板、整胚芯片趋势、E14.5 野生型整细胞及单核心脏参考、野生型谱系参考及心房和心室的变化表。两个官方 RNA 文件都使用每细胞总量归一到 10,000 后取 log1p 的表达。E8.5 文件通过 `obs['sample']` 或官方条形码末尾的文库编号区分两个来源。

```bash
python scripts/prepare_t1_trend.py --output-dir data/geo
python scripts/prepare_t1_heart_reference.py --panel data/T1__test.genes.txt --output-dir data/heart_reference
python scripts/prepare_t1_nuclear_reference.py --panel data/T1__test.genes.txt --output-dir data/nuclear_reference
python scripts/prepare_t1_lineage_reference.py --panel data/T1__test.genes.txt --cache data/lineage_raw --output data/lineage_reference.h5ad
python scripts/download_t1_chamber_counts.py --panel data/T1__test.genes.txt --output-dir data/chambers
python scripts/prepare_t1_chamber_reference.py --counts data/chambers/CD1.h5ad --sources data/chambers/CD1.json --output data/chamber_reference.npz
python -m virtual_embryo.t1.lineage_forecast --source data/E10.5_RNA.h5ad --calibration data/E8.5_RNA.h5ad --reference data/heart_reference/E14.5_heart.h5ad --nuclear-reference data/nuclear_reference/E14.5_wt_nuclei.h5ad --lineage-reference data/lineage_reference.h5ad --chamber-reference data/chamber_reference.npz --cross-gene-dispersion --panel data/T1__test.genes.txt --trend data/geo/stage_effects.csv --interval 5 --source-time 10.5 --target-time 12.5 --cells 4096 --seed 101 --output outputs/T1__test.h5ad
```

`--nuclear-reference` 指向 GSE272154 的 E14.5 野生型心脏 Multiome 核文库，按原始条码和至少 300 个 RNA 分子筛出 8,167 个核。程序分别生成整细胞与单核预测，将单核版的逐基因表达分布按整细胞版的细胞表达排序赋值，再校准每行总量和基因均值。复现原整细胞版时省略 `--nuclear-reference`。单独导出单核版时，将主参考换成该核文件并使用 `--reference-assay nucleus`。[单核原始 RNA 与条码](https://www.ncbi.nlm.nih.gov/geo/query/acc.cgi?acc=GSM8394736)

`--lineage-reference` 来自 GSE126128 的野生型 E7.75、E8.25、E9.25 心区和 GSE230531 的 E8.5 胚体、E16.5 心脏。准备脚本支持 `--wt-cache` 复用 UCSC 原始文件，并支持 `--prepared-8-5`、`--prepared-16-5` 复用已经对齐的 GSE230531 H5AD。备齐参考文件后可直接执行预测命令。`--interval` 是芯片两端相距天数。输出按面板基因顺序写入新的 H5AD。[早期野生型心区](https://cells.ucsc.edu/?ds=mouse-cardiac+wtAll) · [心脏测序](https://www.ncbi.nlm.nih.gov/geo/query/acc.cgi?acc=GSE230531)

`--chamber-reference` 来自 GSE193346 的野生型 CD1 心脏解剖数据。准备程序仅读取 RNA 原始计数，在全部计算前选取 E9.5 和 E14.5。两日龄合计 3,250 个细胞，按心房、心室分别估计同谱系内的表达变化及谱系丰度变化。E9.5 参考早于或等于源日龄且到源日龄的间距不超过预测时长时启用此校正。省略该参数可复现前一版谱系模型。[原始测序与解剖信息](https://www.ncbi.nlm.nih.gov/geo/query/acc.cgi?acc=GSE193346)

`--cross-gene-dispersion` 先调整谱系标志表达与单细胞检出深度的协同变异，再按固定种子将基因分为两组，用一组基因估计另一组的细胞状态。输入为前一步预测。每个细胞的检出基因、每个基因的平均对数表达和每个细胞的分子总量保持一致。使用 `--state-dispersion` 可单独运行第一步。省略两项参数可复现原心腔模型。

## 上一版心脏参考模型

`cardiac_forecast` 仅使用源时点 RNA、面板、整胚芯片变化表与 E14.5 参考生成该版本的 H5AD。

```bash
python scripts/prepare_t1_trend.py --output-dir data/geo
python scripts/prepare_t1_heart_reference.py --panel data/T1__test.genes.txt --output-dir data/heart_reference
python -m virtual_embryo.t1.cardiac_forecast --source data/E10.5_RNA.h5ad --reference data/heart_reference/E14.5_heart.h5ad --panel data/T1__test.genes.txt --trend data/geo/stage_effects.csv --interval 5 --source-time 10.5 --target-time 12.5 --cells 4096 --seed 101 --output outputs/T1__test_round2.h5ad
```

`--reference` 为已对齐的 E14.5 心脏 H5AD，`obs['sample']` 标识两个测序样本。`--reference-time` 默认 14.5。`--interval` 是芯片趋势的测量跨度，源阶段和预测阶段分别由 `--source-time`、`--target-time` 指定。参考准备程序支持 `--offline`，从已保存的矩阵、基因表和来源清单重建参考。[E14.5 心脏参考来源](https://www.ncbi.nlm.nih.gov/geo/query/acc.cgi?acc=GSE230531)

## 历史神经模型的输入

推理支持 NPZ（`x` 数组或 SciPy CSR）、NPY、H5AD（读取 `X`）。表达矩阵为细胞 × 32,285 基因，列顺序与 `models/t1/genes.json` 一致，取值为 `log1p(10000 × composition)`。

继续训练需要 `train_8.5.npz`、`train_9.5.npz`、`train_10.5.npz` 三个 SciPy CSR 文件，每阶段 1,024 行；配对表须对应这些行及其顺序。模型目录需包含 `training/` 初始化权重和 `prepared/` 配对资产。

### 历史神经模型推理

```bash
python -m virtual_embryo.t1.predict --input data/t1_input.npz --output-dir outputs/t1 --source-time 9.5 --target-time 10.5
```

| 参数 | 说明 |
|---|---|
| `--input`、`--output-dir` | 输入文件与新输出目录，必填 |
| `--source-time`、`--target-time` | 源时刻和目标时刻，必填 |
| `--model-dir` | 默认 `models/t1`；设置 `VIRTUAL_EMBRYO_ASSETS` 时使用其下的 `t1` |
| `--seed` | 默认 `101` |

输出 `candidate.npy`、`genes.json`、`audit.json`；9.5→10.5 还生成磁盘中间数组。

## 第一轮年龄趋势模型

先生成 GSE28389 芯片的逐基因变化表。脚本逐张核对日龄、野生型、GPL1261 平台和 MAS5 默认单芯片绝对信号。正式预测的 `stage_effects.csv` 使用三张 E9.5 和两张 E14.5 芯片。早期回测的 `from_e85.csv` 使用三张 E8.5 和同两张 E14.5 芯片。每张芯片独立按其探针组信号的截尾均值缩放，下载记录与散列保存在 `sources.json`。[GEO 数据集](https://www.ncbi.nlm.nih.gov/geo/query/acc.cgi?acc=GSE28389) · [MAS5 算法](https://bioconductor.org/packages/3.23/bioc/html/affy.html)

```bash
python scripts/prepare_t1_trend.py --output-dir data/geo
python -m virtual_embryo.t1.age_prior --source data/E10.5_RNA.h5ad --panel data/T1__test.genes.txt --trend data/geo/stage_effects.csv --interval 5 --horizon 2 --cells 4096 --seed 101 --output outputs/T1__test.h5ad
```

`--interval` 为两次外部测量相距的天数，`--horizon` 为源阶段至预测阶段的天数。`--source` 使用每细胞线性总量归一到 10,000 后取 log1p 的 RNA 表达。`--trend` 包含基因名称和自然对数变化量 `log_ratio`。正式候选从 E10.5 的 24,979 个细胞等概率无放回抽取 4,096 个。输出基因依照 `--panel` 的行顺序。

## 两个历史阶段的外推

T1 可从两个连续观测阶段预测更晚的细胞群体。模型从最近阶段无放回抽取细胞，结合 fullELBO30 预测的基因均值和两个观测阶段的变化趋势，调整每个细胞已检出基因的表达量，每行在线性空间归一化到 10,000。

```bash
python -m virtual_embryo.t1.transport --previous data/E9.5_RNA.h5ad --source data/E10.5_RNA.h5ad --previous-time 9.5 --source-time 10.5 --target-time 12.5 --panel data/T1__test.genes.txt --cells 4096 --output outputs/T1__test_internal_transport.h5ad
```

两个 H5AD 按基因名称与模型列顺序对齐。`--cells` 默认 4,096，`--seed` 默认 101，`--model-dir` 可指定权重目录。`--panel` 指定提交所需的基因顺序，省略时采用模型顺序。输出 H5AD 使用稀疏表达矩阵。

## 训练

```bash
python -m virtual_embryo.t1.train all --data-dir data/t1 --output-dir outputs/t1_train
```

| 配方 | 默认初始化与训练 |
|---|---|
| `full-elbo` | `training/original.pt`；seed 22，30 epoch |
| `teacher` | `training/fullELBO30.pt`；seed 11、22、33，各 144 步 |
| `all` | 先训练 fullELBO30，再用其输出训练三个教师 |
| `control` | 从零训练；固定 seed 1，12 epoch |

| 参数 | 说明 |
|---|---|
| `--data-dir`、`--output-dir` | 训练数据目录与新输出目录，必填 |
| `--model-dir` | 默认 `models/t1` |
| `--prepared-dir` | 默认模型目录下的 `prepared/` |
| `--checkpoint` | 指定 full-elbo 或 teacher 的初始化网络 |
| `--seed` | full-elbo 的种子；单独 teacher 时可选择一个种子；all 的教师仍为 11、22、33 |
| `--epochs`、`--max-steps` | control/full-elbo 的 epoch 数；各配方的更新步数上限 |
| `--initialization`、`--device` | control 初始化统计 JSON；control 训练设备，默认 `cpu`，可选 `cuda:0` |

从零训练 control 需另外提供全量训练矩阵及十二个 epoch 的配对表；`--prepared-dir` 必填：

```bash
python -m virtual_embryo.t1.train control --data-dir original_full_train --prepared-dir original_control_prepared --initialization models/t1/control_initialization.json --output-dir outputs/control
```

每个配方子目录输出 `model.pt`、`inference.pt`、`training.json`。将完整 `all` 结果装配到新模型目录后，通过推理的 `--model-dir` 使用：

```bash
python -m virtual_embryo.t1.assets --trained-run outputs/t1_train --base-model-dir models/t1 --destination models/t1_retrained
```

## 留出集评估

```bash
python -m virtual_embryo.t1.evaluate --prediction outputs/t1/candidate.npy --target data/t1/dev_10.5.npz --output outputs/t1/heldout_metrics.json
```

`--prediction` 为预测 NPY，`--target` 支持上述输入格式，`--output` 为结果 JSON。默认读取 `models/t1/prepared/probe.joblib`，可用 `--probe` 指定 probe，或用 `--model-dir` 指定模型目录。
## 使用两份已有的预测

已有两种参考各自的预测时，两份文件须使用相同源 RNA、目标日龄、面板、细胞数和随机种子。下面的命令将单核预测中每个基因的表达分布按整细胞版的细胞顺序赋值。原细胞的表达相等时使用其邻近细胞的该基因平均表达区分，最后恢复每细胞分子量及核参考的平均表达。

```bash
python -m virtual_embryo.t1.reference_marginals --whole-prediction outputs/T1_whole.h5ad --nuclear-prediction outputs/T1_nucleus.h5ad --output outputs/T1_marginals.h5ad
```
