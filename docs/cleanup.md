## 核验结果

- T1：五个真实 checkpoint × 三个时段的采样逐元素一致；三个完整推理分支逐元素一致。ELBO 全部分项、一次 Adam 更新、连续两次教师梯度预算更新、control 随机初始化与首步更新均一致。
- T2：10 组历史、外推、baseline 和 128 行推理逐值一致；两任务全部三对分位映射重拟合一致；心脏数据准备结果一致；成熟 control 和心脏续训各两次更新后的全部参数一致。
- T3：Mab 53,742 行、Gata 24,826 行各三个随机种子的表达、坐标、行索引、权重和基因名逐值一致。两组 2048 行基因重排一致；1024 行校准精确重建；PCA8 投影一致；mean8 十二步更新一致。
- 最终测试：启用原工作区回放后，32 项全部通过，另有 4 个子测试通过，总用时 17.70 秒。常规运行时，3 项依赖原工作区的 T1 回放检查默认跳过。
- 官方客户端测试使用模拟请求；本次整理没有消耗新的官方测试次数。

验证环境为 Python 3.12、PyTorch 2.6.0、NumPy 2.2.6、SciPy 1.15.3、scikit-learn 1.7.2。详细原始回放记录存于本地 `Cleanup_20261114`。

原 control 的全量重建需要原服务器的训练矩阵和十二个 epoch 配对表；随原模型下载的本机文件提供了 checkpoint、初始化统计和继续训练数据。T3 当前训练条件为 Mab21l2 和 Gata4。
